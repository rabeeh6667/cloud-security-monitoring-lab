# Project Methodology

## Phase 1: Infrastructure Setup

- Created AWS EC2 Ubuntu Instance
- Configured Security Groups
- Installed Nginx

## Phase 2: Reconnaissance

- Performed Nmap Scanning
- Enumerated Open Services
- Captured Network Traffic

## Phase 3: Attack Simulation

- Created SSH Test User
- Performed Hydra Brute Force Simulation
- Generated Authentication Logs

## Phase 4: Detection & Response

- Installed Fail2Ban
- Monitored SSH Logs
- Automatically Blocked Attacking IP
