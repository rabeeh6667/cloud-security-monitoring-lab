# Grafana + Loki Dashboard

## Overview

Grafana and Loki are used to provide centralized log monitoring and security event visualization.

## Objectives

- Monitor SSH authentication failures
- Visualize Fail2Ban events
- Monitor Nginx activity
- Create a threat detection dashboard

## Planned Dashboards

### Dashboard 1
SSH Failed Login Monitoring

### Dashboard 2
Fail2Ban Event Monitoring

### Dashboard 3
Nginx Access Monitoring

### Dashboard 4
Security Event Overview

## Expected Benefits

- Real-time monitoring
- Security event visualization
- Threat detection analytics
- SOC-style dashboard experience
